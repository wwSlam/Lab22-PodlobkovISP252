## Тема

Dictionary и HashSet в C#.

## Что реализовано

- хранение исключений в HashSet;
- добавление и удаление исключений;
- подготовка и разделение текста на слова;
- подсчёт частот в Dictionary;
- вывод общей статистики;
- безопасный поиск слова через TryGetValue.

## Короткие ответы

1. Что должно быть уникальным в Dictionary и в HashSet?

Ответ: В Dictionary уникальны ключи, значения повторяются, а в HashSet уникален каждый элемент.

2. Чем отличается повторное добавление в HashSet от Dictionary.Add() с существующим ключом?

Ответ: HashSet.Add() при повторе просто возвращает false и ничего не меняет программа продолжает работать. Dictionary.Add() с существующим ключом выбрасывает исключение ArgumentException, и программа аварийно завершается

3. Почему для поиска по неизвестному ключу удобно использовать TryGetValue()?

Ответ: TryGetValue() безопасно проверяет наличие ключа и сразу получает значение: если ключ есть — возвращает true и записывает значение в out-переменную, если нет — возвращает false без исключения. Это заменяет два действия (ContainsKey + [key]) одним и не даёт программе упасть на отсутствующем ключе.
